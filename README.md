# Hi, I'm Stephen

I'm a software engineer at NETGEAR, based in Ireland. Outside work I'm building [Stackportfolio](https://stackportfol.io?utm_source=github-profile&utm_medium=readme), where developers can show the stack they use, backed by the projects they've built.

## Work

I joined NETGEAR on the web team. I worked on the rollout of the new website, moving from a legacy Tridion site to Salesforce Commerce Cloud with the PWA Kit front end. That included building new Contentstack components so the content team could keep improving the UI themselves. I also worked on the cart and checkout revamp, moving from an ARIA checkout to a new Stripe checkout.

I've since become an AI champion. Right now that mostly means working with the finance team, helping them automate their processes and build their own apps and skills.

I'm also part of the company's AI platform team, which is quite new. There I research models, harnesses, caching strategies and other optimisations, for engineering and non-engineering teams, and I have some input into how we use AI across the company.

My work account is [netgearstephen](https://github.com/netgearstephen).
